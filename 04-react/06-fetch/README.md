# 06 - Fetch API

This folder contains React examples using the browser Fetch API.

## Files

| File | Topic |
|---|---|
| `FetchData.jsx` | GET request and displaying users |
| `SearchUser.jsx` | Search API call using `useEffect` |
| `SearchUserDebounce.jsx` | Debouncing search API calls |
| `UserFormPostApi.jsx` | POST form data to an API |

## Main concepts

- `fetch()`
- GET and POST requests
- `useEffect`
- Dependency arrays
- Controlled inputs
- `onChange`
- `onSubmit`
- `event.preventDefault()`
- `JSON.stringify()`
- Request headers
- Loading and error handling
- Debouncing with `setTimeout()` and `clearTimeout()`

## API used

https://jsonplaceholder.typicode.com/users

JSONPlaceholder is a fake REST API for practicing API calls. POST requests are simulated and do not permanently save data.
