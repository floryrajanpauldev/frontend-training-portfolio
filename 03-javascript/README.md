# JavaScript / ES6 Training

This module covers modern JavaScript features introduced with ES6 (ECMAScript 2015) and later commonly used JavaScript features.

## Project Setup

This project was created using **Vite** with Vanilla JavaScript.

### Create the Project

```bash
npm create vite@latest
```

Select:

```text
Framework: Vanilla
Variant: JavaScript
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal.

---

## ES6 Topics

The training covers modern JavaScript features such as:

* `let` and `const`
* Template literals
* Arrow functions
* Default parameters
* Destructuring
* Spread operator
* Rest parameters
* Enhanced object literals
* `for...of`
* Promises
* `async/await`
* Modules
* Classes
* `Map` and `Set`

Each topic includes practical examples and explanations.
