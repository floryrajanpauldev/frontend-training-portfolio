Element	Purpose
<!DOCTYPE html>	Declares the modern HTML document and puts the browser in standards mode
<html lang="en">	Root element and declares the document language
<head>	Contains document metadata
<meta charset="UTF-8">	Specifies character encoding
<meta name="description">	Provides a description of the page
<title>	Defines the document title
<body>	Contains the page's visible content
<h1>	Main heading
<p>	Paragraph
